Toujours travailler en TDD (Red → Green → Refactor).

**Why:** Demande explicite de l'utilisateur pour adopter ce workflow sur le projet YamMaster.

**How to apply:** Pour chaque nouvelle fonctionnalité ou bug fix, commencer par écrire un test qui échoue, puis implémenter le minimum pour le faire passer, puis refactoriser. Ne jamais écrire de code de production sans test correspondant d'abord.
